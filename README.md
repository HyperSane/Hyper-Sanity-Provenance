## Private-source note

The source repository `HyperSane/OBSIDIAN` remains private because it contains unrelated private and unpublished material.

Its history was intentionally reset after the Git object store grew to several gigabytes. The surviving May 25, 2025 root commit is therefore a preserved snapshot, not the beginning of Hyper-Sanity.

Raw historical source files and the archived PDF are intentionally excluded from this public repository.
