## Structural comparison

| Function | Hyper-Sanity Paradox / RCR (2025) | Recursive Constraint Falsification (2026) |
|---|---|---|
| Self-correction | Framework examines and updates its own assumptions | Claims and assumptions remain exposed to revision |
| Error target | Contradictions, value-outcome dissonance, recursive incoherence | Failed constraints, rival-model divergence, auxiliary assumptions |
| Iteration | Resolutions are themselves tested again | Tests and failed predictions feed further revision |
| Structural change | Prune, reweight, replace, or refactor affected structures | Narrow, revise, or drop claims and auxiliaries |
| Recursive feature | Modified output returns to the evaluation cycle | Updated claims remain within continuing falsification and calibration |
| Scope | Logic, ethics, beliefs, institutions, philosophy, technology | Reality-facing claims, models, metaphysical and scientific interpretation |

This table documents functional correspondences. It does not, by itself, establish how those correspondences arose.

## Preservation method

The full historical Hyper-Sanity source files remain private because the underlying Obsidian vault contains unrelated private and unpublished material. Public excerpts, commit identifiers, screenshots, Git object references, and SHA-256 hashes are used to document provenance without publishing the complete private vault.

The May 25, 2025 commit is a surviving repository snapshot following an intentional history reset caused by multi-gigabyte Git object growth. It should therefore be read as a surviving evidence point, not as the origin date of Hyper-Sanity.
